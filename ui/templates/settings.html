Debug / Testing

Knobs intended for controlled experiments and A/B comparisons. Hidden from the rest of the page unless testing mode is on. Even when values are saved here, they only take effect at runtime while testing mode is enabled — toggling testing mode off makes the pipeline fall back to its in-code defaults without erasing your saved values.

Testing mode

When on, the temperature overrides below are applied to every relevant API call. When off, the qc_analyzer uses its in-code defaults: extractor & cross-checks at temperature=0, judge (API engine) at the Anthropic default (~1.0). Claude Code judge runs at whatever the CLI defaults to and isn't affected by these overrides.

Temperature overrides

Greedy decoding (0) is best for structured extraction. Higher values introduce variation — useful for N-of-K ensemble experiments only. Range 0–1.
